# Fahd Shop

Amazon-style multi-page shop demo.

## Features
- Product browsing with search, filters, and sorting
- Shopping cart, wishlist, and checkout
- Real-time chat between customers and host
- Admin dashboard with product/order management
- Fahd AI - built-in AI chat assistant (via Ollama)

## Open
You can open `index.html` directly.

## Optional local server
Install Node.js, then run:
`npm start`
